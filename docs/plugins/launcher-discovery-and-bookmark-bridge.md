# 启动器检索与浏览器书签操作

## 更新与验证准备

本次功能同时涉及主程序的 Rust 后端和 `local-launcher` 插件前端。本次源码的主程序版本为 **2.2.10**。免扩展删除需要新主程序和新启动器前端配套更新；已发布插件的兼容版本问题按约定暂不调整。先重新构建/更新主程序，再更新启动器插件。

插件发布仍使用现有 `pnpm plugins:tag` 流程：选择 `local-launcher`、递增插件版本。发布前另行核对最低主程序版本。该流程负责生成新的远程标签、归档校验值和市场索引。本次没有发布远程标签或安装包，保留现有已发布插件的版本与归档校验值。

更新后，在启动器右上角打开“启动器设置”，执行一次“重新扫描”。旧数据库会自动增加 metadata 列；手动添加的条目、图标和搜索历史不需要清空。

## 应用检索

- 复用注册表、开始菜单、桌面快捷方式、Get-StartApps 和 Windows 执行别名来源。
- 所有扫描入口共用过滤规则，排除卸载程序、已失效路径和已知内部 helper。普通系统应用（例如画图）可以正常显示。
- Windows 执行别名默认隐藏，可在设置中开启“显示辅助工具与执行别名”。已知卸载程序与内部 helper 不受此开关影响；用户仍可以显式手动添加条目。
- Codex 依据包标识 `OpenAI.Codex_*` 修正显示名称，保留原名称作为搜索别名。不根据“ChatGPT”这个名称修改其他应用。
- 额外目录最多 10 个，要求存在且为绝对目录；扫描深度最多 4 层，每个目录最多遍历 20,000 个条目。便携应用也可以直接手动添加。
- 同名应用按启动目标去重，不再仅按标题合并。快捷方式保留 `.lnk` 的参数和工作目录。
- 页面检索与全局搜索共用后端匹配规则，支持名称、别名和现有拼音检索。

## 书签来源与隐藏

- 每个书签保留浏览器、配置文件、配置文件身份、浏览器节点 ID、逻辑文件夹路径、实际存储文件和原始标题/URL。
- 相同 URL 合并为一项，但保留全部来源节点。URL 的路径大小写与尾部斜杠不再被抹除。
- Chromium 使用 Bookmarks 中的节点 ID；Firefox 使用 GUID，与浏览器扩展 API 的书签 ID 对应。
- 页面提供浏览器筛选、来源摘要和来源详情；全局搜索结果也展示来源摘要。
- “从启动器隐藏”持久化记录目标，后续重扫不会重新显示。可以在“隐藏的项目”中恢复。原应用/浏览器书签不受影响。
- 完整扫描更新来源并清除过期的扫描条目。任一已发现的书签文件读取失败时，本轮保留旧索引且不标记扫描成功，后续扫描可以重试。

## 免扩展删除浏览器原书签

读取与删除都复用已发现的本地浏览器配置文件，不需要导出扩展、注册本地主机、建立连接或绑定配置文件。旧的 Native Messaging 命令、扩展源码和连接设置已移除。首次调用启动器后端时，会清理本应用的旧注册项；迁移会移除旧绑定表和永久隐藏已删节点的表。已加载到浏览器的旧扩展可由用户自行移除，不编辑浏览器扩展设置。

### 一次确认流程

1. 移除浏览器来源书签时，直接打开一个确认窗口。在同一窗口选择“删除浏览器原书签”或“从启动器隐藏”。
2. 单来源自动选中；多来源必须明确勾选。窗口显示浏览器、配置文件、逻辑文件夹路径和存储文件。
3. 完全退出对应浏览器，包括后台进程。状态自动检查，仍在运行的来源不可提交；应用不会自动结束浏览器。
4. 点击确认后再次检查进程与插件启用状态，仅从后端索引解析原文件路径和节点身份。路径必须属于当前扫描能发现的浏览器配置文件。
5. 原文件备份到 `%LOCALAPPDATA%\SnippetsCode\BookmarkBackups\<唯一目录>`，同一文件内的节点统一校验并提交。每个备份目录保存 `restore-info.json`，记录原文件路径、具体来源与备份时间，便于识别需要恢复的配置文件。成功后立即更新启动器来源与搜索缓存。

### 写入与恢复

- Chromium：校验节点 ID、原始 URL、原始标题、文件版本及校验值；只移除选中的 URL 节点。保留 GUID、同步元数据、自定义字段和未选来源，包括 Edge 的额外根目录。重新计算 MD5 及已有的 SHA256 校验值，再使用 Windows `ReplaceFileW` 替换，不直接截断原文件。
- Firefox：使用 SQLite Backup API 保存完整、包含 WAL 已提交数据的数据库备份，通过事务更新书签、文件夹顺序、祖先修改时间、引用计数，以及已同步节点的删除记录。任一节点变化时，当前配置文件的事务回滚。
- 文件损坏、节点变化、占用、浏览器重新启动、备份失败或格式不支持时，返回具体原因，不报告成功。不同文件的结果独立返回，部分失败不会隐藏未删来源。
- 恢复时先完全退出浏览器，再用备份替换对应原文件并重新扫描。Firefox 备份文件为完整 `places.sqlite`，其中也包含原浏览历史。应用不使用永久删除节点的过滤表，因此恢复后可重新检索。

此方式修改本机文件。浏览器账号同步可能重新合并远端数据，不能承诺删除云端或其他设备书签；确认页明确显示此边界。保留 Chromium 同步元数据，不靠清空同步信息强行改变用户的账号同步状态。

实现格式依据：[Chromium BookmarkCodec](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/components/bookmarks/browser/bookmark_codec.cc)、[Firefox Bookmarks](https://searchfox.org/mozilla-central/source/toolkit/components/places/Bookmarks.sys.mjs) 与 [Firefox Places triggers](https://searchfox.org/mozilla-central/source/toolkit/components/places/nsPlacesTriggers.h)。第三方浏览器格式如与已知校验规则不一致，会拒绝写入。

## 手动回归清单

| 场景 | 预期 |
| --- | --- |
| 搜索 Codex / 原搜索别名 | 找到 Codex 主应用；启动目标正确 |
| 扫描卸载程序、内部 helper、失效路径 | 不展示；画图等普通应用仍可用 |
| 增加便携应用目录 | 重扫后发现应用，手动条目保留 |
| 同名不同目标 | 不被标题去重误合并 |
| 同一 URL 位于不同浏览器/配置/文件夹 | 合并展示但详情保留全部来源 |
| 隐藏 → 重扫 → 重启 | 保持隐藏，恢复后可见 |
| 浏览器筛选与全局来源搜索 | 来源匹配且没有错误归属 |
| 仅删除一个来源 | 对应浏览器节点消失，其他来源保留 |
| 浏览器仍在运行、书签改名或 URL 变化 | 阻止写入，提示关闭浏览器或重新扫描 |
| 浏览器文件被占用、备份失败、并发变化 | 保留原文件，返回具体原因 |
| 浅色 / 深色 / 默认窗口 | 对话框、来源详情和操作按钮沿用共享主题 |

建议用临时测试书签验证原书签删除；本次代码验证没有操作用户的浏览器书签。
