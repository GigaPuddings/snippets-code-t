# 启动器检索与浏览器书签操作

## 更新与验证准备

本次功能同时涉及主程序的 Rust 后端和 `local-launcher` 插件前端。主程序版本已调整到 **2.2.10**，启动器最低兼容版本也设置为 2.2.10。先重新构建/更新主程序，再更新启动器插件。

插件发布仍使用现有 `pnpm plugins:tag` 流程：选择 `local-launcher`、递增插件版本，并设置最低主程序版本为 2.2.10。该流程负责生成新的远程标签、归档校验值和市场索引。本次没有发布远程标签或安装包，保留现有已发布插件的版本与归档校验值。

更新后，在启动器右上角打开“启动器设置”，执行一次“重新扫描”。旧数据库会自动增加 metadata 列；手动添加的条目、图标和搜索历史不需要清空。

## 应用检索

- 复用注册表、开始菜单、桌面快捷方式、Get-StartApps 和 Windows 执行别名来源。
- 所有扫描入口共用过滤规则，排除卸载程序、已失效路径和已知内部 helper。普通系统应用（例如画图）可以正常显示。
- Windows 执行别名默认隐藏，可在设置中开启“显示辅助工具与执行别名”。已知卸载程序与内部 helper 不受此开关影响；用户仍可以显式手动添加条目。
- Codex 依据包标识 `OpenAI.Codex_*` 修正显示名称，保留原名称作为搜索别名。不根据“ChatGPT”这个名称修改其他应用。
- 额外目录最多 10 个，要求存在且为绝对目录；扫描深度最多 4 层，每个目录最多遍历 20,000 个条目。便携应用也可以直接手动添加。
- 同名应用按启动目标去重，不再仅按标题合并。快捷方式保留 `.lnk` 的参数和工作目录。
- 页面检索与全局搜索共用后端匹配规则，支持名称、别名和现有拼音检索。

## 书签来源与隐藏

- 每个书签保留浏览器、配置文件、配置文件身份、浏览器节点 ID、逻辑文件夹路径、实际存储文件和原始标题/URL。
- 相同 URL 合并为一项，但保留全部来源节点。URL 的路径大小写与尾部斜杠不再被抹除。
- Chromium 使用 Bookmarks 中的节点 ID；Firefox 使用 GUID，与浏览器扩展 API 的书签 ID 对应。
- 页面提供浏览器筛选、来源摘要和来源详情；全局搜索结果也展示来源摘要。
- “从启动器隐藏”持久化记录目标，后续重扫不会重新显示。可以在“隐藏的项目”中恢复。原应用/浏览器书签不受影响。
- 完整扫描更新来源并清除过期的扫描条目。任一已发现的书签文件读取失败时，本轮保留旧索引且不标记扫描成功，后续扫描可以重试。

## 删除浏览器原书签

### 首次连接

1. 启动器设置 → 浏览器连接 → “准备连接并导出扩展”。这一步由用户主动触发，在当前用户 HKCU 注册 Native Messaging host，导出路径为 `%LOCALAPPDATA%\SnippetsCode\BookmarkBridge`。
2. Chrome、Edge、Brave：打开扩展管理页，开启开发者模式，加载导出的 `chromium` 目录。Firefox：在 `about:debugging` 临时加载导出的 `firefox/manifest.json`。Firefox 长期分发需要签名扩展；临时扩展关闭浏览器后需要重新加载。
3. 打开扩展弹窗，选择浏览器、填写当前配置文件的可识别名称，然后点击“连接”。
4. 返回启动器设置，刷新连接，明确绑定对应浏览器配置文件。一个扩展连接只能绑定一个配置文件。

目前原书签删除支持 Chrome、Edge、Brave、Firefox。其他已扫描浏览器仍支持来源展示和隐藏。移动主程序安装位置或安装路径发生变化后，重新“准备连接”即可更新 host 路径。

### 删除流程

1. 进入列表编辑模式，选择书签的移除按钮。
2. 第一层确认选择“删除浏览器原书签…”。
3. 第二层确认显示所有具体来源，只有已绑定且在线的来源可选。勾选后点击“确认删除所选原书签”。
4. 扩展检查节点 ID、原始 URL、原始标题和请求有效期，然后调用浏览器 `bookmarks.remove`。只删除所选节点，不删除文件夹或未选择的来源。

浏览器的账号同步行为遵循浏览器自身设置。写入失败、节点变化、连接中断或超时会显示错误，不报告成功。收到成功回执后，启动器记录已删除的来源，避免浏览器文件落盘之前重新展示旧节点。

实现不会直接写浏览器的 Bookmarks JSON / SQLite 文件，不自动启动浏览器或安装扩展。移除本地连接会注销 Native Messaging host 并取消待处理请求；禁用插件也会断开内部连接并拒绝新操作。删除插件自有数据时会注销连接。

## 手动回归清单

| 场景 | 预期 |
| --- | --- |
| 搜索 Codex / 原搜索别名 | 找到 Codex 主应用；启动目标正确 |
| 扫描卸载程序、内部 helper、失效路径 | 不展示；画图等普通应用仍可用 |
| 增加便携应用目录 | 重扫后发现应用，手动条目保留 |
| 同名不同目标 | 不被标题去重误合并 |
| 同一 URL 位于不同浏览器/配置/文件夹 | 合并展示但详情保留全部来源 |
| 隐藏 → 重扫 → 重启 | 保持隐藏，恢复后可见 |
| 浏览器筛选与全局来源搜索 | 来源匹配且没有错误归属 |
| 仅删除一个来源 | 对应浏览器节点消失，其他来源保留 |
| 浏览器离线、书签已改名或 URL 已变化 | 不误删，提示刷新/重新连接 |
| 浏览器有未落盘数据或暂时锁定 | 读取失败保留旧索引，可以重试 |
| 浅色 / 深色 / 默认窗口 | 对话框、来源详情和操作按钮沿用共享主题 |

建议用临时测试书签验证原书签删除；本次代码验证没有操作用户的浏览器书签。
