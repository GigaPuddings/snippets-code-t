# Markdown 编辑器

笔记使用 CodeMirror 6，以 Markdown 文本作为编辑与保存的数据模型。实时阅览通过 Lezer 语法树和 CodeMirror decorations 展示格式，不将富文本 JSON 或渲染后的 HTML 转回正文。代码片段继续使用独立的 `CodeMirrorEditor`。

大纲、反向链接与表格组件位于 `MarkdownEditor/components`；反向链接状态与图片文件路径工具随编辑器维护。代码与笔记编辑器共用 `UI/EditorStatusBar.vue` 和引擎无关的右键菜单。旧 TipTap 编辑器、专用扩展、JSON 序列化器及其依赖已移除，旧版 HTML 笔记与富文本剪贴板仍通过共用转换器读取。

大纲只在正文或语法树更新时提取；搜索结果按文档与查询缓存，移动光标只在已缓存位置中查找当前匹配项。表格控制器按源码及容器前缀复用解析结果和单元格范围，正文或前缀变化时重新计算。缓存不参与持久化。

## 三种模式

- **实时阅览**：光标或选区所在行保留 Markdown 标记；其他行显示标题、强调、行内代码、链接、列表等样式。图片点击后进入对应源码；表格保留网格，点击单元格直接编辑该格的 Markdown。按住 Ctrl 点击双链或外部链接执行跳转。
- **源码模式**：使用同一个 EditorState，显示全部源码。切换不会重建文档或清除撤销历史。
- **阅读模式**：通过共用渲染器生成经过清理的 HTML，不接受编辑；返回编辑时沿用原文档。HTML 标签不会因为切换模式被序列化为其他写法。

快速搜索的 Markdown 预览复用 `MarkdownPreview`，通过 `styles/markdown.scss` 中的 `rendered` mixin 与工作区阅读模式共享排版。窄预览栏只调整外层留白；双链交给宿主导航，外链使用系统浏览器，任务复选框保持只读。本地 Markdown 文件使用文件预览接口返回的正文，异步结果在切换条目或卸载后失效。代码片段继续复用只读的 `CodeMirrorEditor`，不再由前端截断到 1600 字符；本地文件仍保留后端读取大小限制。

最近删除也复用这两种只读组件。侧栏选择条目后，按需读取回收站正文；附件仍以笔记原位置解析，保留期内的附件目录不会被孤立附件清理移除。回收站内容位于应用数据目录，不参与工作区搜索或 Git 同步。新删除内容保留 30 天；没有到期时间的旧条目在升级后首次读取时获得完整的 30 天保留期，并持久化到期时间。应用启动、读取回收站及运行中每小时清理当前工作区的过期条目；应用关闭期间的过期内容在下次启动时清理。恢复仍按原始字节写回原位置，不覆盖已有文件。列表与预览区均支持立即删除，确认后仅移除所选回收站记录及笔记副本，不触碰原位置的新文件，也不在此操作中直接删除附件。删除请求执行期间阻止重复操作；失败后保留确认框，允许重试。

正文中的空行、缩进、行尾双空格和换行符均有意义。页面直接持有 Markdown，保存检查比较完整文本。后端解析 Frontmatter 时只移除结束分隔符后的换行和一个约定的空行，正文其余空白保留。Frontmatter 的元数据格式仍由现有存储服务管理。

## 输入与块操作

有序条目中 Enter 插入与条目正文对齐的无编号续行，连续输入正文不会生成新序号；空续行再次 Enter 退出当前列表层级，子列表返回父条目的正文。引用中的列表保留引用前缀。在实时阅览的续行中主动输入下一编号及空格，会将该行转为同级的下一条目，恢复旧编辑器的输入规则；源码模式与代码块保留字面输入。无序列表和任务列表沿用 Markdown 列表续行。`a.`、`i.` 是普通文本；需要真实的多级列表时使用数字列表或无序列表及缩进。

实时阅览的非当前行与阅读视图采用同一编号规则：列表从首项的数字起连续计数，各子列表独立计数。例如源码连续写三个 `1.`，两种视图均显示 `1、2、3`；源码中输入的数字不因预览而改写。当前行显示实际输入的 Markdown 标记，使用与预览标记相同的宽度，切入编辑时正文不会横移。

代码围栏使用已有的 JavaScript、TypeScript、Java、JSON、HTML、CSS 语言支持。其他语言保留源码并显示普通代码文本。代码中的花括号换行复用已有工具，Ctrl+Enter 可从围栏后继续输入正文。

实时阅览与阅读模式沿用原有文档字号、行高、内容宽度、代码块及表格主题变量。预览中的空行承担块间距，标题、列表和引用使用 CodeMirror 可测量的行内 padding，避免重复增加间距或破坏光标坐标。代码块悬停显示语言与复制操作；语言修改只更新开始围栏，支持撤销，阅读模式保留代码高亮与复制。

图片粘贴与拖入继续调用附件服务。实时阅览中右击图片，通过“图片缩放”选择 25%、50%、75%、100%、125%、150%、200%，或输入 25 到 200 之间的整数百分比。菜单可选择将比例应用到本笔记全部图片，并提供打开文件位置和删除图片；不显示缩放滑轨或图片悬浮按钮。缩放只修改图片对应的 Markdown/HTML 范围，保留原相对路径，单次批量操作可一次撤销。标准相对图片路径按笔记目录解析，旧版 `../assets/` 路径继续按工作区附件目录解析。预览失败时复用附件恢复接口尝试恢复已清理的图片。

表格使用 GFM 语法。实时阅览中点击单元格直接编辑该格的 Markdown，其他单元格继续显示渲染结果。单元格输入直接修改原文对应范围，与正文共用撤销历史，支持中文组合输入、连续空格、字面管道符与富文本粘贴。表格工具栏随当前表格定位，提供网格调整尺寸、对齐、行列增删和删除表格。对齐范围按钮使用列图标或表格图标表示当前范围，悬停显示文字说明；点击后可选择“当前列”或“整张表格”，默认为当前列，再选择左对齐、居中或右对齐。整表操作覆盖所有表头和正文单元格。各列对齐不同时，整表范围下不高亮任何对齐按钮。对齐操作仅修改 GFM 对齐分隔行，保留单元格原文、空格及撤销重做后的光标位置。行列与尺寸操作会规范化当前表格的管道符与空格，其余正文不参与序列化；引用和列表容器的前缀保留。

Tab / Shift+Tab 在单元格间移动，最后一格按 Tab 新增一行；Ctrl+Enter 在当前行下方插入一行。单元格内 Enter 或 Shift+Enter 插入 `<br>`，最后一格末尾按 Enter 移到表格后的正文。制表符分隔的区域和 HTML 表格可从当前格起粘贴。拖动单元格右边界可调整列宽；与旧版保存行为一致，列宽仅用于当前编辑视图，GFM 文件不记录宽度，切换模式或重新打开会恢复自动布局。合并单元格和持久列宽不属于当前 GFM 数据模型。

显式 Markdown 和已有 Markdown 结构的剪贴板文本按原文插入；网页剪贴板提供 HTML 时保留标题、强调等格式并转换为 Markdown。代码区始终采用纯文本。AI 和异步剪贴板替换携带文档标识与版本，原文改变或切换笔记后拒绝覆盖旧选区。上传图片在文档加载或切换后不会插入过期位置。

表格之外，Tab 在光标处插入两个空格，Shift+Tab 移除光标前最多两个空格或一个制表符；存在选区时按整行缩进或取消缩进。代码块内 Ctrl+A 选中代码正文，Ctrl+Shift+A 选中当前代码行。

代码块背景位于 CodeMirror 选区层下方，手动拖选和快捷键全选均显示完整选区；选区坐标范围与正文区域一致，不覆盖两侧留白。普通换行、列表续行或退出、代码括号换行及 Shift+Enter 都请求将新光标滚入可视区域。

文档以已闭合的代码围栏结束时，在实时阅览中单击代码块下方的正文留白会新增普通段落并移入光标，可单独撤销和重做。已有末尾空行时复用空行；源码模式、只读状态和未闭合围栏不执行该操作。新增换行保留文档原有的 LF 或 CRLF 格式。

## 范围与验证

这是面向 Markdown 文件的编辑基础，不代表完整兼容 Obsidian。当前支持标准 Markdown、GFM 表格与任务列表，以及项目原有的 `[[笔记标题]]` 双链。Obsidian 插件 API、Dataview、Canvas、块引用、嵌入语法、Callout 和数学公式专用渲染没有在本次迁移中实现；未识别的语法作为原文保留。

新增语法时应同时检查 Lezer 识别、实时阅览、阅读渲染和原文保存，避免只在一种模式下解释语法。预览 HTML 继续通过共用清理函数处理，不将事件属性或脚本接入编辑器。

回归测试位于 `src/components/MarkdownEditor/*.test.ts`，覆盖模式重配、撤销重做、CRLF、列表续行、双链、表格和图片范围修改。存储层正文空白保留测试位于 `src-tauri/src/markdown/metadata.rs`。涉及编辑器改动时还需在实际组件中检查中文输入、模式切换、滚动、搜索、附件、表格、AI 选区和浅色/深色主题。

实时阅览的行高必须由 CodeMirror 可测量的行边框盒贡献。标题间距使用行内 padding，不能用外部 margin；修改标题、分隔线、图片或表格样式后，须实际点击多个标题下方及滚动后的正文，核对光标、鼠标选区和源码行号一致。只验证文档文本或组件是否挂载不能发现坐标偏移。

### 序号专项复测

上一轮缺少重复编号、主动输入下一编号、切入编辑时的横向对齐等场景，专项复测发现并修复了以下问题：

- 实时阅览直接显示源码数字，与阅读视图的连续计数不一致；覆盖重复编号、跳号、零起始、多级列表、引用和括号分隔符。

- 子列表的空续行按 Enter 会退出全部层级；改为回到父条目正文，同时保留引用容器。
- 为压缩空行而设置的 1px 字号会使光标缩成一个点；保留 12px 块间距并恢复正常字号的光标。
