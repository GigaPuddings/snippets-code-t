# 壁纸来源与筛选方案

调研日期：2026-10-21。结论基于官方页面、接口说明及公开列表请求；图片数量和分页数只是当时的观测值。

## 结论

本次保留 Wallhaven 和 Wallspic，使用各自的筛选方式，不增加第三个抓取源。Wallhaven 更适合标签检索、多分类与排行榜；Wallspic 作为桌面分类图库补充。筛选界面随来源改变，共用结果列表、预览、下载和应用操作。在线界面不提供自由文本搜索，壁纸源与筛选项集中在一条可换行的工具栏。

“更好的来源”取决于用途。官方 API、图片质量、标签粒度、接入许可和持续维护成本都需要考虑，不能由图片数量单独决定。

## 来源比较

| 来源 | 已核实能力与限制 | 当前取舍 |
| --- | --- | --- |
| [Wallhaven](https://wallhaven.cc/help/api) | 官方 API 支持分类位掩码、关键词、排序、排行榜时段、随机种子及分页；网站额外提供 Hot。API 文档未列出 Hot，所以继续使用网站页面获取 Hot，失败时不替换成其他排序。 | 主检索源；现有 API／网页适配器直接扩展。 |
| [Wallspic](https://wallspic.com/album/for_desktop) | 桌面目录提供自身分类及 New／Popular 排序；关键词搜索是站内搜索，与分类目录是不同路径。本次未找到稳定的亚洲女性联合标签入口或面向第三方的公开 API 文档。 | 保留为补充源，使用实际分类目录；不承诺亚洲女性筛选。 |
| [Pexels](https://help.pexels.com/hc/en-us/articles/4405588861721-Can-I-use-the-API-as-a-wallpaper-app) | 官方说明限制独立壁纸／图库应用，但允许主用途不同的产品添加背景选择能力，也列出了插件例外及署名要求。 | 适合后续评估的摄影源，不能简单判定禁止或直接免配置接入；需确认插件用途、API key、署名与自动轮换展示方式。 |
| [Unsplash](https://help.unsplash.com/en/articles/2511257-guideline-replicating-unsplash) | 限制复制核心图库体验，允许在有其他用途的产品中集成；API 要求图片热链接、署名、下载／设为背景事件回报。 | 可作为后续摄影源候选，需要按官方 API 规范单独设计接入。 |
| [Bing Wallpaper](https://www.microsoft.com/en-us/bing/features/bing-wallpaper/) | 官方产品提供每日精选图片和最近七天浏览。本次公开首页图片 JSON 也能返回数据，但这不等于存在有稳定承诺、可自由再分发的第三方壁纸图库 API。 | 更适合独立的“每日精选”功能，不作为人物标签或大规模检索源的替代。 |
| [WallpaperFlare](https://www.wallpaperflare.com/terms-of-use) | 图片由用户提交，条款说明版权及使用责任。本次未核实到稳定的官方第三方 API。 | 不为增加网站数量再引入一套网页抓取和下载适配。 |

## 已实现的筛选

### Wallhaven

- 排序：相关度、随机、最新、浏览量、收藏榜、排行榜、热门。
- 排行榜时段：近一天、近三天、近一周、近一个月、近三个月、近六个月、近一年；仅排行榜显示该控件并发送 `topRange`。
- 分类：General／Anime／People 对应三位掩码，可组合选择，至少保留一种。
- 自然是独立的主题预设，以 `nature` 标签筛选通用＋动漫范围；可以进一步只保留通用或动漫，切换到人物时关闭自然条件。该状态随配置保存，并用于分页和自动轮换。
- 仅选择 People 时提供可选的“亚洲女性”，通过 `+asian +women` 请求来源标签；不通过图片外观猜测。
- Random 同一批次复用六位种子，翻页不重新随机；刷新或更改筛选开启新批次。
- 保留原有最低屏幕分辨率及 1080p 回退策略，界面移除分辨率徽标和排行榜说明。

### Wallspic

- 排序：最新／热门。
- 使用网站桌面目录的 23 个分类及“全部分类”，包括人物、自然、动漫、汽车、游戏、动物等；目录统一使用 `/album/<category>/.../for_desktop`。
- 在线界面不再提供关键词搜索。打开图库时清除旧配置中的关键词，避免隐藏的自由文本条件继续影响结果；后端仍保留旧请求兼容。
- 不显示 Wallhaven 的排行榜时段、多选分类或亚洲女性开关，也不对每张列表图片追加详情请求核验族群和性别。
- 本地继续剔除方图和竖图；筛选后某页为空也不代表来源已到底，后续分页仍可加载。

## 兼容与维护

旧请求未携带新筛选对象时，继续兼容旧版分类含义。旧 Wallhaven 人物配置迁移成 People + 亚洲女性；旧自然分类恢复为自然主题预设；显式关闭自然后不会被旧分类字段重新启用。新版图库仍清除旧的自由文本关键词。旧 Wallspic 人物配置改为其原生 People 目录，不再添加亚洲女性条件。

新增筛选随配置持久化，并进入轮换历史／候选缓存作用域，避免切换排行榜时段或分类后从旧结果中轮换。托盘仍使用已有四个常用排序入口，网站切换时把不支持的排序恢复为热门。

本次涉及 Rust 后端和主应用语言目录，测试时必须使用同一源码的宿主；单独导入前端插件目录不能给旧宿主补上筛选处理。插件目录安装和构建命令见 [插件 README](../plugin-registry/packages/wallpaper-switcher/README.md)。

网页抓取仍受网站结构变化和网络条件影响。没有把“页面暂时可访问”视为接口长期稳定的保证，也没有新增依赖、API 密钥或外部代理服务。
