# Product icons

Common UI icons come from Lucide; brand icons come from Simple Icons or reviewed brand assets.
Only product-specific icons belong here. Import an SVG as `~icons/app/<filename>`.

Use a `24 24` viewBox and `currentColor` for monochrome icons. Preserve brand colors when required.
Avoid scripts, event handlers, external references, and fixed IDs shared between instances.
Document the source and license alongside any third-party asset.
